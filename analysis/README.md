# analysis/

| Folder | Contents |
|---|---|
| `graphical/` | Chart builders. Deterministic and script-generated, so a figure can always be regenerated from current data. |
| `notebooks/` | Exploration only. Nothing load-bearing may live solely in a notebook. |
| `reports/` | Written findings. Figures and numbers are pulled from the data, never typed in. |

When a notebook produces something worth keeping, move it into `graphical/` or `scripts/`. A
notebook is a place to think, not a place to store results.
